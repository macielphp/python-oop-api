


### Estrutura do projeto
```
/python-oop-api/
│
├── main.py                              → Ponto de entrada da aplicação
└── modelos/
    ├── avaliacao.py                     → Classe que representa avaliações de clientes
    ├── restaurante.py                   → Classe Restaurante (principal)
    └── cardapio/
        ├── item_cardapio.py            → Classe abstrata base para itens do cardápio
        ├── bebida.py                   → Classe Bebida
        ├── prato.py                    → Classe Prato
        └── sobremesa.py                → Classe Sobremesa
```
